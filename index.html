Kiến Trúc Phân Lớp Sạch Sẽ & Giải Pháp Chống Chặn IP

Clean 4-Layer Architecture
Kiến Trúc Phân Tầng (Clean Architecture) src/
1. Data Layer (src/data/) DChart • CafeF • SQLite
2. Strategy Layer (src/strategy/) TA • CANSLIM • Scoring
3. Backtest Layer (src/backtest/) Simulation • Metrics
4. Bot Layer (src/bot/) Async • UI Cards • Chart
• Nguyên lý Single Responsibility: Phân lập tuyệt đối giữa các tầng.
• Phân đoạn mã nguồn có cấu trúc: Tổ chức module mạch lạc, dễ mở rộng.
Giải Pháp 4 Lớp Chống Chặn IP Khi Cào CafeF Anti-WAF Defense
1. Header Spoofing
Giả lập trọn bộ header chuẩn Chrome: Accept-Language, Referer, Sec-Ch-Ua.
2. User-Agent Rotation
Xoay vòng ngẫu nhiên 5 danh tính trình duyệt (Chrome macOS/Win, Safari, Firefox, Linux).
3. Throttling with Jitter
Giãn cách tối thiểu ≥ 1.0s kèm độ trễ ngẫu nhiên 0.1 - 0.3s triệt tiêu dấu vết máy móc.
4. Exponential Backoff
Khi gặp mã 429/403, tự lùi bước theo hàm số mũ 2^k + jitter rồi chuyển tiếp Fallback.
Cơ chế Auto-Fallback 3 cấp: Direct DChart API $\rightarrow$ CafeF SolieuGD $\rightarrow$ SQLite Cache. Mất mạng bot vẫn chạy!
Tự chủ dữ liệu & không phụ thuộc vnstock: Loại bỏ triệt để nguy cơ crash do gọi sys.exit() và giảm thời gian nạp từ 5.4s xuống 1.2s.
